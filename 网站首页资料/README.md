# 实验4 CSS布局实战——网站首页
## 项目说明
本项目为Web应用开发技术实验4，实现学成在线网站首页。
1. 使用Flex实现导航栏、banner横幅、精品推荐、学科课程、版权页脚一维布局
2. 使用Grid布局完成精品课程、学科课程卡片二维网格布局
3. position:fixed实现顶部固定导航栏，body设置padding‑top防止页面被导航遮挡
4. transition + transform实现卡片hover悬浮上浮阴影交互效果
5. @media媒体查询实现移动端适配，PC端5列卡片，移动端变为2列
## 文件目录
- index.html：页面结构
- css/base.css：基础重置样式
- css/index.css：页面布局样式
- images：图片素材
- uploads：页面宣传、课程图片
## 运行方式
VSCode安装Live Server插件，右键index.html选择Open with Live Server打开预览
